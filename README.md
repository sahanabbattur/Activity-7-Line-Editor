# Simple Line Editor Using C

## Project Description
The Simple Line Editor is a basic text editor developed using the C programming language. It allows users to insert, delete, display, save, load, and search text lines.

## Features
1. Insert Line
2. Display Document
3. Delete Line
4. Save Document
5. Load Document
6. Search Word
7. Count Lines and Words

## Technologies Used
- C Programming Language
- GCC Compiler
- Visual Studio Code

## Data Structure
A two-dimensional character array is used to store multiple lines of text.

## How to Compile
Open the terminal in the project folder and enter:

```bash
gcc line_editor.c -o lineeditor
```

## How to Run

```bash
./lineeditor
```

On Windows PowerShell, use:

```powershell
.\lineeditor.exe
```

## How to Use
Run the program and select an option from the menu by entering its number. Follow the instructions displayed on the screen.

## Conclusion
This project demonstrates the use of arrays, functions, loops, strings, and file handling in C programming.
